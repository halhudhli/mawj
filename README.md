## ✨ وش يميز Luxo

| | |
|---|---|
| 🎟️ **بطاقة Luxo Pass** | ملف شخصي على شكل تذكرة سينما بلمعة هولوغرام تتحرك مع ميلان الجهاز، تنقلب وتطلع إحصائيات المشاهدة |
| 🚀 **شريط Luxo Dock** | شريط عائم: القسم المفتوح يتمدد بتدرج لوني، وحلقة ضوء عند كل تنقل. أو شريط **جانبي** (يمين بالعربي، يسار بالإنجليزي) |
| 🤖 **رفيق Luxo** | مساعد Gemini داخل التطبيق وداخل المشغّل: ملخص بدون حرق، "وش صار لين الحين؟"، تعريف بالممثلين، ويقرأ ذوقك ويقترح |
| 🌐 **ترجمة تلقائية للعربي** | إذا ما فيه ترجمة عربية، الرفيق يترجم الإنجليزية ويضيفها للمشغّل |
| 🧭 **طابور الاستكشاف** | كروت تسحبها يمين للي يعجبك ويسار للي ما يعجبك |
| 🎨 **تصميم Luxo** | كروت زجاجية وعناوين متدرجة ومفاتيح متحركة في كل الصفحات، مع شدة توهج تختارها |

## المميزات

<details open>
<summary><b>🏠 التصفح والاكتشاف</b></summary>

- أقسام **أفلام** و**مسلسلات** و**أنمي** و**قوائمي** في الشريط، وكل قسم يتخفى أو يظهر
- **وش أشوف الليلة؟**: تختار مزاجك ويقترح عليك
- مجموعات ذكية، ورفيق يقترح أعمال مشابهة
- **ثيمات المواسم**: زينة رمضان والعيدين واليوم الوطني ويوم التأسيس
</details>

<details open>
<summary><b>👤 الملف الشخصي وذوقي</b></summary>

- بطاقة **Luxo Pass**، وتحتها الإعدادات على شكل **قاعات** مرقمة
- **ذوقي**: وصف ذكي للذوق، و«قاعد أتابعها» و«خلّصتها»، وتقويم الحلقات الجاية
- **13 وسام** تنفتح مع المشاهدة، و**خريطة مشاهدة** لآخر 6 شهور
- **تقييمي الشخصي** (نجوم بأنصاف) مع ملاحظة، و**قوائم خاصة** بأسماء وإيموجي
- **بطاقة مشاركة** بمقاس الستوري فيها البوستر وتقييمك
</details>

<details open>
<summary><b>▶️ المشاهدة</b></summary>

- مؤقت النوم (بالدقائق أو لين نهاية الحلقة)
- **لقطة شاشة** تنحفظ في الصور، و**تكرار مقطع (A-B)**، و**إضاءة حول الفيديو** بألوان المشهد
- **ترتيب المصادر حسب الجودة** وإخفاء نسخ الكام
- تنسيق مرتب لمعلومات كل مصدر (الدقة، التخزين، الصوت، الحجم)
- التنزيل للمشاهدة بدون نت
</details>

<details open>
<summary><b>🧭 التنقل</b></summary>

- الشريط **علوي أو سفلي أو جانبي أو تلقائي** (جانبي على التابلت بالعرض)
- يختفي وقت التمرير، وترتيب الأزرار يدوي، والأسماء تظهر أو تختفي
- **ضغط مطوّل**: الرئيسية تفتح «وش أشوف الليلة؟»، والبحث يفتح الكيبورد، والمكتبة تفتح التنزيلات
- شارة على المكتبة بعدد حلقات اليوم
</details>

<details open>
<summary><b>🛠️ وأكثر</b></summary>

- التاريخ **الهجري** والأرقام العربية
- **قفل التطبيق بالبصمة**
- تذكير الحلقات الجديدة، والإضافة لتقويم الجوال
- **استوديو الثيمات**: ألوان جاهزة مثل «ليل الرياض» و«غروب العلا»، وتقدر تشارك الثيم بكود
- خطوط مدمجة (ثمانية، تجوّل، المراعي، IBM Plex Arabic…) ومعها خطوطك الخاصة
- تسجيل الدخول بحساب **نوفيو** ومزامنته، ومعه Trakt وSimkl وMDBList
- نسخة احتياطية لكل إعدادات Luxo
- **تحديثات من داخل التطبيق**

وكل إضافة لها زر تشغيل وإيقاف في **المظهر ← إضافات Luxo**.
</details>

## التثبيت والتحديث

1. نزّل ملف `Luxo-x.y.z-arm64-v8a.apk` من [**آخر إصدار**](../../releases/latest) وثبّته.
2. بعد كذا التحديثات توصلك من داخل التطبيق: **الملف الشخصي ← التحديثات**.

> النسخ كلها موقّعة بنفس المفتاح، فكل تحديث يتثبت فوق القديم بدون ما تضيع بياناتك.
> التطبيق للاستخدام الشخصي، وما فيه أي محتوى. المحتوى كله من الإضافات والمصادر اللي تضيفها أنت.

## البناء

البناء يصير تلقائياً بـ GitHub Actions مع كل تحديث للفرع `main`، ويطلع منه إصدار جديد برقم `1.0.<رقم البناء>`.

**الأسرار المطلوبة** في *Settings ← Secrets and variables ← Actions*:

| الاسم | الفايدة |
|---|---|
| `LUXO_UPDATE_TOKEN` | رمز GitHub بصلاحية **Contents: Read-only** على هذا المستودع، عشان التحديث من داخل التطبيق يقدر يقرأ الإصدارات |
| `LUXO_GEMINI_KEY` | مفتاح Gemini الافتراضي لرفيق Luxo والترجمة التلقائية (ويقدر المستخدم يغيّره من الإعدادات) |

البناء محلياً:

```bash
./gradlew :androidApp:assembleFullDebug
```
